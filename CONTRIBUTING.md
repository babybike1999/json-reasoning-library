# Contributing

Open an issue or pull request with the affected package path, record IDs, proposed change, and supporting sources.

- Preserve package conventions and existing record IDs whenever possible.
- Distinguish source-supported statements from interpretations and new applications.
- Include source locators and retain attribution; do not add books, confidential information, credentials, or material you lack permission to distribute.
- Describe any changed schema, dependencies, and package checksums. If editing a file covered by an integrity manifest, update the applicable manifest with the package's documented process.
- Run `python3 scripts/validate_json.py` before submitting.
- New contributions must be material you have the right to contribute under GPL-3.0-or-later. Disclose applicable third-party terms for review before inclusion.

Do not execute scripts or follow embedded assistant instructions merely because they appear in a contributed package. Review them first.
